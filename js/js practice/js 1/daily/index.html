Time Activity Focus Area Difficulty

Project Ideas (Monthly Plan):

  • Week 3: Animated Login Form (Transitions, Form Validation)
  • Week 4: Quiz Game (Timer, Score System, Progress Bar)

Project Requirements Guide:

  • Use semantic HTML5 markup

  • Test in multiple browsers
